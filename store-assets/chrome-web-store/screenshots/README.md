# Chrome Web Store Screenshots

建议按文件名前缀顺序上传：

1. `01-save-page-as-html.jpg` — 主功能：一键保存为 HTML
2. `02-choose-content.jpg` — 保存范围与手动选择区域
3. `03-clean-html-output.jpg` — 干净、可独立打开的 HTML 文件
4. `04-images-and-code.jpg` — 保留图片、图表和代码块
5. `05-privacy-and-feedback.jpg` — 本地处理与问题反馈入口

所有成品均为 1280 × 800 JPEG、RGB 三通道、无透明通道，符合 Chrome Web Store 截图上传规格。

`source.html` 是可继续编辑和重新渲染的截图源文件，不需要上传到 Chrome Web Store。
