What HTML to Markdown means here

HTML to Markdown on this page means taking messy page HTML — or a public URL — and turning the main content into clean GitHub Flavored Markdown you can edit, commit, or paste into notes. The primary controls sit above: a URL field with placeholder Paste any URL — https://example.com/article and a Convert button. Below the fold, Have raw HTML instead? Paste or upload it here opens a paste/upload path with Upload .html and side-by-side HTML / MARKDOWN panes.

This is the reverse of the homepage Markdown to HTML converter. Use this page when you already have a web article, docs page, or saved HTML file and you want Markdown source. When you later need a printable packet, send Markdown into Markdown to PDF. For PDFs that already exist as text-layer files, PDF to Markdown is the better entry point.

Output aims for usable GFM: headings, lists, links, images (with absolute URLs when converting from a page), tables, and fenced code where Turndown + GFM plugins can recover them. Scripts, styles, nav, footer, and similar chrome are stripped during extraction so you spend less time deleting site chrome by hand.

People search for HTML to Markdown when they want an editable source again: cloning a docs page into a repo, turning a newsletter archive into notes, or feeding cleaner text into another tool. URL convert covers the "I have a link" case. Paste/upload covers the "I already have the HTML" case. Both produce Markdown you can diff, search, and keep offline.

The page stays English-only in its default chrome and FAQ copy. Labels you will see repeatedly are Convert, Copy Markdown, Download .md, Open in Markdown → HTML, Upload .html, and the paste disclosure summary — those are the controls the how-to sections refer to on purpose.

Paste or upload raw HTML

When a site blocks fetching, or you already saved a page with your browser, expand Have raw HTML instead? Paste or upload it here ↓. Use Upload .html, paste into the HTML pane, or drag and drop onto that pane. Markdown updates in the adjacent MARKDOWN pane as you paste; use Copy Markdown under that section when it looks right.

Full saved documents (including pages that contain a root html/body or known content roots such as WeChat’s #js_content) go through the same main-content extraction heuristics used for URL converts, so you often get the article body instead of the entire browser chrome.

Paste conversion does not require a network round-trip to mdtohtml. The HTML you typed or uploaded is parsed with Turndown in your browser. That is the path to prefer for private HTML snippets, email exports, and pages you can open but the public web cannot fetch on your behalf.

Why some pages fail to convert

URL convert is best-effort. The live fetcher tries, in order: a direct fetch of the URL from your browser, then public helpers at allorigins and corsproxy. Results that look like captchas, access-denied walls, or nearly empty text are rejected and the next attempt runs. Known hard hosts (for example certain social and paywalled article hosts) skip straight to guidance: save the page locally and upload HTML, or use the browser extension on the page you can already see.

Heavy client-rendered apps may return a shell HTML file with little article text. Login walls return HTML you are not authorized to read via anonymous fetch. In those cases the tool cannot invent content it never received. Saving the rendered page from your browser (HTML only) and using the paste/upload section is the honest workaround.

We do not claim every URL on the internet converts. We do claim the UI tells you when a fetch failed and points you at paste/upload or the extension instead of silently inventing Markdown.

Cleaning tips for usable Markdown

After Convert, skim headings — extraction may promote the page title as an H1 and keep a Source line. Remove leftover empty links, tracking query strings, and duplicate titles. Wide tables sometimes need a pass in your editor. Code blocks usually survive when the source used semantic pre/code; highly styled span soup may need manual fences.

If images are missing, check whether the source used lazy-load attributes; the extractor promotes common data-src patterns when src is empty, but not every CDN pattern is covered. Absolute URLs are applied when a base URL is known from a URL convert.

When the Markdown is tidy, you can keep editing locally, open it in Markdown to HTML for a themed page, or export a packet with Markdown to PDF. For syntax questions, the cheat sheet shows exact HTML output for common constructs.

A short cleanup checklist that usually pays off: (1) confirm the top heading is the article title you want, (2) delete empty image links, (3) normalize bullet markers if a CMS emitted mixed lists, (4) wrap suspicious indented code in fences, (5) spot-check one table. After that, the file is usually ready for git or for a second pass through Markdown to PDF.

If you only needed a reading copy and not editable source, you might prefer HTML to PDF elsewhere on the site — but for long-term notes, Markdown remains easier to merge and search than a stack of saved HTML files.

HTML → Markdown vs Markdown → HTML / PDF

  • This page — HTML to Markdown — URL or HTML in, GFM Markdown out.
  • Markdown to HTML — Markdown in, themed HTML out for sharing in a browser.
  • Markdown to PDF — Markdown in, print/PDF out with KaTeX, Mermaid, and themes.
  • PDF to Markdown — Text-layer PDF in, Markdown out (not OCR).

Pick by artifact: scrape and edit as Markdown here; publish as HTML on the homepage; archive or attach as PDF on Markdown to PDF. Keeping Markdown as the editable source avoids locking notes inside a PDF you cannot diff.

FAQ

How do I convert a URL to Markdown?

Paste the URL into the box (placeholder: Paste any URL — https://example.com/article) and press Convert. The tool fetches the page, extracts main content, and shows GitHub Flavored Markdown in the MARKDOWN pane.

Can I convert raw HTML instead of a URL?

Yes. Expand Have raw HTML instead? Paste or upload it here, then paste HTML or use Upload .html. Markdown appears in the adjacent MARKDOWN pane; use Copy Markdown when ready.

Why do some pages fail to convert?

Some hosts block automated fetching, require login, show anti-bot walls, or render almost everything in the client after load. The tool tries a direct fetch, then public fetch helpers; if the HTML looks empty or blocked, it opens the paste/upload section and suggests saving the page locally or using the browser extension on the page you can already view.

Is it free?

Yes. No signup, no watermark.

Is it private?

Pasted or uploaded HTML is converted locally in your browser and is not uploaded to mdtohtml for conversion. URL convert fetches the page you asked for — first from your browser, and if that fails, through public fetch helpers (not an mdtohtml upload of your Markdown). Your converted Markdown stays in the page until you copy or download it.
