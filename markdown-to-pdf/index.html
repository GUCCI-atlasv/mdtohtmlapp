Frequently asked questions

Is this Markdown to PDF converter free?

Yes — 100% free with no paid tier. No signup, no credit card, no watermark and unlimited exports. Every tool on mdtohtml.app works the same way.

How does the PDF export work?

Your markdown is rendered into a themed page and opened in your browser's print dialog — choose "Save as PDF". Everything happens locally; nothing is uploaded.

Does it support LaTeX math and diagrams?

Yes. Inline $...$ and block $$...$$ equations render with KaTeX, and fenced ```mermaid code blocks render as flowcharts, sequence diagrams, Gantt charts and more — in both the live preview and the exported PDF.

Are tables, code blocks and a table of contents included?

Yes. GFM tables, fenced code blocks and task lists render correctly, and a table of contents is added automatically when your document has four or more headings.

Can I control page size and margins?

Yes — the print dialog lets you choose paper size, margins and orientation. The themes are optimized for A4 and US Letter.
