What this Markdown to PDF converter does

This page is a free Markdown to PDF converter for documents you already have as Markdown — READMEs, AI exports, meeting notes, specs, and reports. Paste Markdown into the editor, upload a .md file, or drag and drop onto the MARKDOWN pane. The PDF PREVIEW pane shows a themed layout. When the preview looks right, click Export PDF and choose Save as PDF in your browser print dialog.

Unlike copy-paste into a word processor, the preview here is built for Markdown: headings, lists, GitHub Flavored Markdown tables, fenced code, task lists, KaTeX math, and Mermaid diagrams. An automatic table of contents appears when the document has four or more headings. Themes (GitHub, Docs, Magazine, Minimal) change typography and spacing so the PDF reads like a finished handout rather than raw source.

The job on this URL is a printable or shareable PDF. If you need shareable HTML instead, use the homepage Markdown to HTML converter. If you are going the other direction — HTML or a page URL into Markdown — use HTML to Markdown. To pull text from an existing PDF, try PDF to Markdown (text-layer PDFs).

Everything for Markdown → PDF runs in your browser. Your source is not uploaded to mdtohtml servers for conversion. That matters when notes include customer names, unreleased product copy, or internal links you would rather keep local.

Math, Mermaid, tables, code, TOC

Capability claims below match the live tool on this page (verified against assets/render.js and the sample document loaded in the editor).

  • KaTeX math — Inline $...$ and block $$...$$ equations render in the preview and in the exported print view.
  • Mermaid diagrams — Fenced blocks marked mermaid (for example flowcharts) render as diagrams in preview and export.
  • Tables & code — GFM tables, fenced code blocks, and task lists are supported in the themed document.
  • Table of contents — When the document has four or more headings (h1–h3), a Contents nav is inserted automatically at the top of the document. Shorter docs skip the TOC.

The sample Markdown already in the editor demonstrates math, a Mermaid flowchart, a table, and a code block so you can click Export PDF without preparing a file first. Replace the sample with your own notes when you are ready.

Theme choice affects how those elements look on the page, but it does not remove math or diagram support. If a Mermaid block fails to parse, the export still includes the rest of the document; fix the diagram syntax and the preview will update when you edit.

Page size, margins, and print tips

This Markdown to PDF page does not show dedicated page-size or margin fields in the toolbar. The only layout controls above the fold are Upload .md, the theme select, and the editor itself. Print CSS shipped with the export sets a default @page margin of 18mm and avoids breaking inside pre blocks, tables, blockquotes, and images where the browser allows.

Paper size (A4, Letter, and others), custom margins, and orientation come from your browser print dialog after Export PDF. Themes are readable on A4 and US Letter; if headers feel tight, widen margins in the dialog or shorten long unbroken code lines in the source.

Tips that usually help:

  • Confirm PDF PREVIEW before exporting — what you see is what the print view starts from.
  • Allow pop-ups for this site if Export PDF is blocked; the tool opens a blob window for printing.
  • Turn on background graphics in the print dialog if a theme uses colored heading accents you want preserved.
  • Very wide tables may need a landscape orientation or slightly smaller margins in the dialog.
  • Use Download .html when you want to archive the themed document or open it later without re-pasting Markdown.

There is no watermark and no account gate on export. If you need HTML you can host or email as a single file, prefer the homepage Markdown to HTML flow; this page is optimized for the print/PDF path.

Markdown to PDF vs Markdown to HTML

Both tools share local rendering ideas — themes, privacy, and rich Markdown — but the deliverable differs:

  • Markdown to PDF (this page) — Best when the artifact must be attached, printed, or archived as PDF. Export goes through the browser print dialog.
  • Markdown to HTML — Best when you want a self-contained HTML page to share or publish without forcing a PDF reader.
  • HTML to Markdown — Reverse direction: clean Markdown from a URL or pasted HTML, then optionally bring that Markdown back here for PDF.
  • PDF to Markdown — Extract a text layer from a PDF into Markdown (not OCR for scans).

A practical loop for research notes: convert a public article with HTML to Markdown, tidy headings in your editor, then use Markdown to PDF for a reading packet. For engineering READMEs that must stay on GitHub as Markdown but also go to stakeholders as PDF, keep the .md as source of truth and export from this page when you need the packet.

Do not treat PDF as a substitute for editable source. Keep the Markdown file; regenerate the PDF when the source changes. That avoids drifting copies and keeps math and Mermaid regenerable.

Privacy: nothing uploaded

Markdown → PDF on mdtohtml.app is designed so conversion stays on your device. The MARKDOWN editor, theme selection, PDF PREVIEW iframe, and Export PDF print view all run in the browser. Your Markdown is not sent to mdtohtml for rendering.

Third-party CDNs may load libraries such as marked, DOMPurify, KaTeX, and Mermaid so the page can render. That is separate from uploading your document body to our servers. If you work on a locked-down network, confirm those script hosts are allowed, or download the themed HTML when online and print offline later.

Drafts can be shared with the homepage converter through browser localStorage when you jump between tools — still on your device, not a cloud project folder. Clear site data if you use a shared computer after pasting sensitive notes.

We do not add a watermark, and we do not require signup to export. If your compliance review needs “no upload for document conversion,” this page’s local export path is the feature that matters.

FAQ

Is this Markdown to PDF converter free?

Yes. No signup, no watermark, no page limits on the free tool.

How does the PDF export work?

The PDF PREVIEW pane renders in your browser. Export PDF opens that preview in a print view on your device — choose Save as PDF. Nothing is uploaded.

Does it support LaTeX math and diagrams?

Yes. KaTeX renders inline and block math, Mermaid renders fenced diagram blocks, and GFM tables, code blocks, and an automatic table of contents (when the document has four or more headings) are included in preview and export.

This page does not expose separate page-size or margin controls in the toolbar. Default print CSS uses an 18mm page margin. When you click Export PDF, your browser print dialog lets you choose paper size (such as A4 or Letter), margins, and orientation.

Is my Markdown uploaded?

No. Conversion runs locally in the browser.
