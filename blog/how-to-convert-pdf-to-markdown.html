How do I convert a PDF to Markdown?

Published 2026-10-04

Short answer: If the PDF has a real text layer, pull that text out and write it as Markdown headings and paragraphs. If the PDF is a scan or a photo of a page, there is no text to pull out, and this will not read it.

Why a PDF does not paste as Markdown

A text PDF stores each character with a position on the page. It does not store headings or lists. Paste it into a doc and you get one flat block. To get Markdown, mark headings with # and split the rest into paragraphs and lists.

A scanned PDF is only a picture. Reading it needs OCR, which this tool does not do. Use a PDF you can already select text in.

What to do

  1. Open PDF to Markdown and drop the file in. It stays in your browser and is not uploaded.
  2. Check the preview. Headings and paragraphs come from the text layer only.
  3. Copy the Markdown or download the .md file.
